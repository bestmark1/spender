Where the number came from

Official

A cost figure returned by the provider's own billing API. OpenAI, Anthropic and xAI report cost; OpenAI and Anthropic add tokens and a model breakdown, xAI adds models. Cost — not balance.

Estimated

Derived, and labelled as such. DeepSeek publishes no cost history, so Spender computes spend from saved balance decreases — and says so on the card.

—Unavailable

No report, no number. A metric a provider does not expose is left blank — never rounded down to $0.00.

Calibrated by you

The idea

It knows what it doesn't know.

Every dashboard promises one clean total. To print it, they have to invent the parts nobody reports.

Spender refuses. Where the number is derived it says estimated, shows the method in one line, and keeps it out of the official total. You are the kind of person who knows the difference between a zero and a missing value. So is your spend tracker.

Providers

Every provider, and exactly what it will tell you.

Native SwiftUI

A 340-point panel, sized to what it has to show, that drops out of the menu bar — not a browser in a window. Launches at login, refreshes in the background, and retains the last good snapshot rather than blanking the card.

No account, no backend

There is no Spender server to sign up for and no credential proxy in the middle. The only requests it makes are to the provider APIs you connected yourself, restricted to declared HTTPS origins.

Keys in the Keychain

An OpenAI Organization Admin key, an Anthropic Console Admin key, a team-scoped xAI Management key — the narrowest read-only credential each provider supports, held in the macOS Keychain. Never your inference keys.

Questions

What people ask before connecting a key.

How do I track my OpenAI and Anthropic API spending on a Mac?

Install Spender, connect an OpenAI Organization Admin key or an Anthropic Console Admin key, and the menu bar panel shows what each provider's own billing API reports for today, yesterday and the last 30 days, with tokens and a breakdown by model.

Does Spender send my API keys anywhere?

No. Keys are stored in the macOS Keychain and used only for requests to the providers you connected, over declared HTTPS origins. There is no Spender account, no server and no credential proxy in between.

Which LLM API providers does Spender support?

OpenAI, Anthropic, DeepSeek, Kimi, Qwen (Alibaba Cloud Model Studio), xAI Grok and OpenRouter. Each card says exactly what that provider reports: cost, tokens, balance or credits.

How does Spender know my remaining balance?

DeepSeek, Kimi, xAI and OpenRouter report it themselves, and so does Qwen with read-only billing credentials. OpenAI and Anthropic do not, so you enter it once from their Billing page and Spender subtracts each new official cost report from it.

Why are Gemini, Perplexity and Mistral missing?

An ordinary API key from them can call models but cannot read what the account has spent, and Mistral's billing API needs an Enterprise account. Spender does not use undocumented endpoints, because a wrong number is worse than no number.

Is Spender free?

Yes. It is free and open source under the MIT License and runs on macOS 14 or later. Download the signed, notarized DMG from GitHub Releases, or build it from the source.
